Multi-tenant SaaS where QSA audit firms run PCI DSS assessments end to end — scoping, evidence collection through a client portal, Report on Compliance authoring with DOCX export, and gap and risk analysis. Founder and sole engineer since 2025.

Enterprise auth throughout: passkeys, TOTP 2FA, org-enforced MFA, Entra ID single sign-on and step-up re-authentication. "Cortex", an agentic assistant, answers from a 3,400-chunk methodology corpus via RAG, with usage caps and per-tenant keys. A deterministic ROC parser covers PCI DSS 4.0/4.0.1 across a 250-control guidance layer and 448-question readiness scoring.

Security built in from day one — zero-trust networking, a self-hosted secrets vault, point-in-time backups with sub-minute RPO and a measured 4m34s RTO, weekly restore drills, external penetration testing, DNSSEC/CAA/HSTS, a public status page and security.txt. 2,100+ commits, four locales, zero-downtime deploys.
